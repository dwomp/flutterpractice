## 활용 강의영상

- 인프런 강의: https://www.inflearn.com/course/flutter-netflix-clone-app/dashboard?cid=324976

## 프로젝트 내용
- Firebase에 저장된 콘텐츠를 연동하여 Flutter를 이용하여 구현

## 개발 환경
- Flutter: 3.44.8
- Dart: 3.12.2
- Firebase: Cloud Firestore
- IDE: Visual Studio Code

## 실행 방법

1. 패키지 설치 - flutter pub get
2. Firebase 설정 - dart pub global run flutterfire_cli:flutterfire configure
3. 프로젝트 실행 - flutter run -d edge
